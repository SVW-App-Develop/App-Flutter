# 14단계 : 출석체크
- 구글 지도, Geolocator 플러그인, 다이얼로그

  - 지도 기반 위치 서비스
 
    - 정해둔 특정 위치의 위도, 경도로부터 100미터 이내에서 출근 체크 기능을 제공하는 앱
   
  - 구글 지도 API : 구글 클라우드 플랫폼 콘솔에서 API 키 발급
 
    - 회사 건물 위치, 출근 가능 영역, 현재 나의 위치를 지도 위에 표현
   
  - 건물 위치와 내 현재 위치가 몇 미터 떨어져 있는지 계산
 
    - 출근 체크 가능한 거리인지 확인하는 기능 탑재

- [실습 프로젝트 바로가기](https://github.com/SVW-App-Develop/chool_check.git)

<br>

|개요|설명|
|-|-|
|**프로젝트명**|choll_check|
|**개발환경**|플러터 SDK : 3.24.3|
|**미션**|출근 체크 기능이 있는 앱 구현|
|**기능**|- 구글 지도를 활용해서 지도 UI 구현<br><br>- 현재 위치를 지도에 띄우기<br><br>- [현재 위치로 이동] 버튼을 눌러서 GPS 상의 현재 위치로 이동<br><br>- 출근 가능한 위치로 이동하면 [출근하기] 버튼 눌러서 출근 체크 가능<br><br>- 출근 가능한 위치가 아니라면 [출근하기] 버튼 숨김|
|**조작법**|- 출근 체크가 가능한 위치로 GPX 이동(실제 기기에서는 실제 위치, 시뮬레이터 또는 에뮬레이터에서는 가상 위치)<br><br>- [출근하기] 버튼 탭 후 출근 체크|
|**핵심 구성요소**|- 구글 지도<br><br>- Geolocator<br><br>- 다이얼로그|
|**플러그인**|- google_maps_flutter: 2.10.0<br><br>- geolocator: 13.0.2|
